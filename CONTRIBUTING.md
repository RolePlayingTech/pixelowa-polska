# Współpraca

Repozytorium rozpoczyna się od dokumentacji. Jeśli chcesz zgłosić poprawkę historyczną lub źródło:

1. Opisz lokalizację, obiekt, zakres czasu oraz twierdzenie, które zmieniasz.
2. Dodaj trwały odnośnik do źródła lub sygnaturę archiwalną; napisz, co źródło **bezpośrednio** potwierdza.
3. Dodaj informację o licencji i o tym, czy można publikować skan lub geometrię.
4. Oznacz geometrię/datę jako przybliżoną, jeśli źródło jest nieprecyzyjne.
5. Rozdziel dane od interpretacji. Przy sprzecznych źródłach zachowaj obie hipotezy.

Proponowany obieg: issue → katalog źródeł → ekstrakcja → walidacja automatyczna → recenzja historyczna → PR → zatwierdzony import.

Ważne: kod, dane zewnętrzne, fotografie i skany mogą mieć różne licencje. PR nie może automatycznie zmienić praw materiału wejściowego.
