# Źródła i prawa — rejestr startowy

| Źródło | Co wnosi | Bramka przed użyciem |
|---|---|---|
| GUGiK / Geoportal | współczesne obrysy i modele budynków LoD1 / LoD2 | sprawdź warunki danej usługi, atrybucję i format |
| OpenStreetMap / Geofabrik | współczesne drogi, woda, miejsca | ODbL; zaprojektuj obowiązki dla baz pochodnych |
| OpenHistoricalMap | datowane obiekty historyczne | zweryfikuj licencję każdego importowanego elementu; zwykle CC0 |
| Atlas Fontium / IH PAN | historyczne osadnictwo, granice, drogi | sprawdź prawa konkretnych warstw, CC BY i oddzielne ograniczenia treści |
| NID / mapy.zabytek.gov.pl | zabytki i archeologia | odrębnie sprawdź geometrię, metadane i materiały ilustracyjne |
| Polona / Szukaj w Archiwach | mapy, zdjęcia, plany | prawa i opis przy KAŻDYM obiekcie / skanie |
| MAPSTER | mapy archiwalne WIG | serwis wskazuje użytek niekomercyjny; brak automatycznej zgody na publikację |
| Warszawa1939 | rekonstrukcje i fotografie przedwojenne | wymagana weryfikacja możliwości wykorzystania |

## Procedura dopuszczenia źródła
Zapisz URL, wydawcę, autora, licencję, wymaganą atrybucję, zakres komercyjny, prawa do przetwarzania, redystrybucji, metody importu, hash źródła, datę przeglądu i decyzję recenzenta. Status: pending / approved / blocked.

## Kod porównywalnych projektów
Nie kopiuj Cracow Pixel Map ani Wrocław Pixel Map bez wyraźnej licencji. Publiczny repozytorium bez licencji nie jest automatycznie open source. Allmaps: zweryfikuj licencję konkretnego pakietu (część narzędzi MIT, część aplikacji GPL). iso-cities: MIT; MapLibre GL JS: BSD-3-Clause. Prawa do danych i do kodu rozpatruj osobno.

## Ryzyka prawne
Nie publikuj skanów o niejasnych prawach ani restrykcyjnych oryginałów w publicznym GitHubie. Do produkcji włączaj tylko rekordy z pozytywną kontrolą praw.
