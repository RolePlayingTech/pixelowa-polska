# Onboarding i publikowanie zmian

Repozytorium: https://github.com/RolePlayingTech/pixelowa-polska

1. Przeczytaj README, AGENTS oraz docs/02-product-requirements.md, docs/05-historical-data.md i docs/06-sources-and-licenses.md.
2. Dla nowych zmian zakładaj gałąź i PR; nie wdrażaj automatycznie na produkcję.
3. Aktualny stan pracy prowadź w GitHub Issues; dokument docs/10-backlog.md jest planem.
4. Po każdym imporcie dołącz źródło, wersję, atrybucję, licencję, hash i wynik kontroli.
5. Przeglądaj historię na syntetycznych danych przed użyciem realnych danych.
6. Uruchamiaj minimalne CI; ciężkie zadania GIS poza GitHub Actions.

Repo dokumentacyjne — obecnie nie ma instalowalnej aplikacji. Nie zakładaj istniejących skryptów ani serwerów.
