# ADR-0002 — evidence-first history

Status: proposed.

Historyczny rekord nie jest równoznaczny z pewnym modelem graficznym. Każde twierdzenie o obiekcie ma zakres obowiązywania, precyzję, źródło i osobno ocenioną pewność istnienia, lokalizacji, kształtu i daty.

Nie interpolujemy nieznanych wersji budynków ani historycznych granic. Brak informacji jest jawny. Przy konfliktach zachowujemy alternatywne hipotezy. Weryfikacja ludzi wymagana przed najwyższą kategorią pewności.
