# ADR-0003 — bramka praw do danych

Status: proposed.

Publiczny GitHub nie upoważnia nas do publikowania cudzych skanów, modeli lub baz. Każda importowana warstwa musi zawierać source, license, attribution, allowed_uses oraz rights_review_state. Produkcyjna publikacja z unknown/blocked jest zabroniona.

Oryginały o ograniczonych prawach trzymamy poza repo i publicznymi paczkami. Dla danych OSM sprawdzamy obowiązki ODbL; dla map archiwalnych prawa do skanów i przeróbek.
