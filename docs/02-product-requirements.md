# PRD — wymagania v0.1

## P0 — konieczne dla MVP
- Mapa Polski: płynne pan/zoom, stabilne kadrowanie, działanie na telefonie.
- Jeden globalny suwak daty filtrujący wszystkie warstwy, bez zmiany pozycji i orientacji kamery.
- Wyraźny pixel art, nie wyłącznie rozmyty filtr obniżający rozdzielczość.
- Dane mają przedziały obowiązywania, źródła i szczegółową pewność.
- Brak danych jest wizualnie oznaczony, nigdy nie jest traktowany jako dowód, że obiekt nie istniał.
- Powtarzalny link do czasu, lokalizacji, zoomu i wybranych warstw.
- Ogólnopolska warstwa współczesna oraz jedna dopuszczona prawnie historyczna warstwa ogólnopolska.
- Przynajmniej jeden wiarygodny wycinek zabudowy miasta w więcej niż jednej epoce.
- Karty obiektów z dowodami i statusem praw do materiałów.

## P1
- Porównanie dwóch dat przy tej samej kamerze; podświetlenie tylko potwierdzonych zmian.
- Oś lokalnych wydarzeń, wyszukiwarka historycznych nazw, odtwarzanie czasu.
- Możliwość przełączenia etykiet źródłowych i poziomu niepewności.

## P2
- Uliczny spacer 3D tylko tam, gdzie źródła umożliwiają wiarygodną rekonstrukcję.
- Wycieczki tematyczne, crowdsourcing moderowany, moduły dla edukacji.

## Kryteria akceptacji
Zmiana roku 1935 → 1945 → 2026 nie przestawia kamery. Dla rekordu bez potwierdzonego stanu wyświetlany jest komunikat „brak danych”; nie powstaje fikcyjny model. Żaden obiekt nie może mieć statusu „zweryfikowany” bez źródła. Zestawy danych bez rozstrzygniętej licencji nie są publikowane.
